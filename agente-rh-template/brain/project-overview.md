# Vision y alcance

<!-- QUICK-PROJECT:START -->
## Vision

Disponer de un esqueleto de repo operativo, stack-agnostico, listo para clonar y usar con agente en Antigravity.

## Objetivos

- Reentrada rapida tras interrupciones.
- Estado actual visible en menos de 30 segundos.
- Workflows reutilizables y accionables.
- Memoria viva, sin duplicidades y sin deriva documental.

## Alcance actual

- Estructura base del repo.
- Reglas workspace para agente.
- Mini cerebro inicial.
- Scripts base de soporte y limpieza.

## Fuera de alcance actual

- Implementacion de stack aplicacion (Node/Python/Go/PHP).
- Automatizaciones externas no declaradas en scripts.
